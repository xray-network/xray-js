# XRAY JavaScript SDK runtime

`@xray-network/xray-js` is the public aggregate package for XRAY/Network JavaScript APIs. Its package root
intentionally exports nothing; applications import only the explicit feature or blockchain subpaths they use.

`/mini-app-bridge/react`, and `/mini-app-bridge/testing`.
